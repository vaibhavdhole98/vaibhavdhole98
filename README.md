# 💫 About Me:
💻 I’m Vaibhav Dhole, a passionate and performance-driven Full Stack Developer based in Nagpur, India, with over more than 5 years of experience building scalable, modern web applications using Angular, Node.js, Express.js, and MongoDB.

At Com1 Communication Technologies Pvt. Ltd., I led the migration of a large Angular v10 app to v18, significantly improving performance, maintainability, and aligning the platform with modern web standards.

🔐 I also developed a secure JWT Authentication System, integrating Angular frontend with a Node.js/Express backend, implementing login/signup, token-based access control, protected routes, and interceptor-based authorization—ensuring secure and scalable user management.

📧 Another key achievement is my QR Code Email Sender project—a full-stack solution that automates sending personalized emails embedded with QR codes. Built with Angular, Node.js, MongoDB, and Nodemailer, this solution is ideal for campaigns, invitations, and attendance systems. It reduced manual effort by 40% and achieved 99.9% delivery accuracy.

Previously, at GIF Technologies, I developed a Messaging Mail Module using Angular v5. I enhanced the user interface with search, pagination, and multi-select functionality, improving the email management experience significantly.

🛠️ I’ve also worked on freelance projects like a salon appointment booking website and a real estate landing page, focused on responsive design and clean user interactions. My journey began with a hands-on internship at Cojag, where I built static websites using HTML, CSS, JavaScript, and jQuery.

I thrive on solving real-world problems through clean code, great UI/UX, and continuous learning. Let’s connect if you’re looking for a committed developer who’s always ready to build and improve digital experiences!
